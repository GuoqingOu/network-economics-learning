# 第一次学习：网络、邻接矩阵与基础指标

> 日期：2026-09-05<br>
> 定位：Network Economics 入门单元

## 1. 这次学习要解决什么

第一次学习先不进入复杂模型，只建立一套共同语言：

1. 什么是经济学中的网络？
2. 如何用邻接矩阵表示网络？
3. 最基础的网络指标在经济学上分别意味着什么？
4. 在计算指标以前，研究者必须把哪些问题说清楚？

## 2. 网络是什么

一个网络可以写成

\[
g=(N,E),
\]

其中，\(N\) 是节点集合，\(E\) 是连接集合。

真正重要的不是把数据画成一张图，而是给节点和连接明确的经济含义。例如：

| 网络 | 节点 | 连接 |
|---|---|---|
| 企业供应链 | 企业 | 采购或供货关系 |
| 投入产出网络 | 行业 | 中间投入流动 |
| 社会网络 | 个人或家庭 | 朋友、信息交流或资金往来 |
| 金融网络 | 银行或金融机构 | 债权债务关系 |
| 政策扩散网络 | 地区 | 模仿、竞争或邻近关系 |

同一批节点可以对应多种网络。朋友关系、资金往来和信息交流不能因为节点相同就被视为同一条连接。

## 3. 邻接矩阵

假设网络中有 \(n\) 个节点，可以使用一个 \(n\times n\) 的邻接矩阵 \(G\) 表示连接：

\[
G=(g_{ij}).
\]

在最简单的二元网络中，

\[
g_{ij}=
\begin{cases}
1, & i\text{ 与 }j\text{ 之间存在连接},\\
0, & \text{否则}.
\end{cases}
\]

构造矩阵时要区分三组概念：

- **无向与有向**：朋友关系通常可近似为无向；供应关系通常有明确方向。
- **二元与加权**：是否存在交易是二元关系；交易额可以作为权重。
- **静态与动态**：只观察某一年得到静态网络；逐年观察连接变化得到动态网络。

如果是无向网络，通常有 \(g_{ij}=g_{ji}\)；如果是有向网络，这一条件一般不成立。

## 4. 第一组基础指标

| 指标 | 简单定义 | 主要经济含义 |
|---|---|---|
| 度（degree） | 节点直接连接的数量 | 直接关系是否丰富 |
| 密度（density） | 实际连接占所有可能连接的比例 | 整体网络是否紧密 |
| 路径（path） | 沿连接从一个节点到另一个节点的序列 | 影响或信息可能如何传播 |
| 最短距离 | 两个节点之间最短路径的长度 | 接触成本或传播步数 |
| 连通分量 | 内部节点彼此可达的最大子网络 | 网络是否分裂成互不相连的群体 |
| 聚类系数 | 一个节点的邻居彼此连接的程度 | 局部团体或三角闭合程度 |
| 中心性 | 从不同角度衡量节点的位置 | 识别关键节点，但含义取决于具体指标 |

对于无向二元网络，节点 \(i\) 的度为

\[
d_i=\sum_{j\neq i}g_{ij}.
\]

若网络包含 \(n\) 个节点和 \(m\) 条无向连接，密度为

\[
Density=\frac{2m}{n(n-1)}.
\]

## 5. 中心性不能脱离机制解释

几种常见中心性回答的是不同问题：

- **度中心性**：谁拥有最多直接连接？
- **接近中心性**：谁到其他节点的平均距离最短？
- **中介中心性**：谁更经常位于其他节点之间的最短路径上？
- **特征向量中心性**：谁连接了更多本身也重要的节点？

因此，“中心性较高”本身不是完整的经济结论。研究者还需要解释：为什么该种位置会影响信息、行为、风险或收益？

例如，供应链中的高出度企业可能是重要供应商；高入度企业可能依赖许多供应商。若忽略方向，两者会被混为一谈。

## 6. 三种典型结构

- **星形网络**：一个中心节点连接所有外围节点。传播距离短，但可能高度依赖中心节点。
- **线形网络**：节点依次连接。端点之间距离较长，中间节点具有明显的中介位置。
- **完全网络**：任意两个节点都直接相连。密度最高，但维持连接的成本也可能最高。

网络经济学经常研究的不是哪种结构“看起来更好”，而是在给定收益、连接成本和外部性的条件下，什么网络能够形成、是否稳定、是否有效率。

## 7. 开始一项网络研究前的六个问题

1. 节点具体代表谁？
2. 连接具体代表什么经济关系？
3. 连接是否有方向和权重？
4. 网络在哪个时间点形成，是否可能内生？
5. 数据中没有连接，代表真实不存在还是没有被观测到？
6. 所选指标对应哪一种经济机制？

这六个问题通常比“使用哪个软件包计算中心性”更重要。

## 8. 本次小结

第一次学习只需要记住三点：

1. 网络是带有经济含义的节点与关系，不只是一张图。
2. 邻接矩阵是连接理论模型、数据和计算的基础表示。
3. 网络指标必须服从研究机制，不能先算指标、再寻找解释。
