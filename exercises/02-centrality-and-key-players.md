# 第二次学习配套练习

考虑一个包含七个节点的无向网络：

\[
N=\{A,B,C,D,E,F,G\},
\]

连接集合为

\[
E=\{AB,AC,BC,CD,DE,EF,EG,FG\}.
\]

它可以理解为两个三角形群体 \(ABC\) 和 \(EFG\)，中间通过 \(C-D-E\) 连接：

```text
A---B
 \ /
  C---D---E
          / \
         F---G
```

## 问题

1. 计算每个节点的度，并指出度中心性最高的节点。
2. 计算网络密度。
3. 计算节点 \(D\) 到其他节点的最短距离，并求其接近中心性。
4. 不进行完整计算，先判断哪个节点的中介中心性可能最高，并解释原因。
5. 比较节点 \(C\)、\(D\) 和 \(E\)：为什么度中心性与中介中心性会给出不同排序？
6. 如果政策目标是向尽可能多的直接邻居发送信息，应该优先考虑哪些节点？如果目标是监测两个群体之间的传播，又应该优先考虑哪个节点？
7. 删除节点 \(D\) 后网络发生什么变化？这说明“关键节点”还可以相对于什么目标定义？

<details>
<summary>参考答案</summary>

各节点的度为

\[
d_A=d_B=d_D=d_F=d_G=2,\qquad d_C=d_E=3.
\]

因此 \(C\) 和 \(E\) 的度中心性最高，均为 \(3/6=0.5\)。

网络包含 \(n=7\) 个节点、\(m=8\) 条连接，因此密度为

\[
Density=\frac{2\times8}{7\times6}=\frac{8}{21}\approx0.381.
\]

从 \(D\) 到 \(C\) 和 \(E\) 的距离为 1，到 \(A,B,F,G\) 的距离为 2。距离总和为 10，所以

\[
C_C(D)=\frac{6}{10}=0.6.
\]

节点 \(D\) 的中介中心性最高。任意一个左侧三角形节点与任意一个右侧三角形节点之间的最短路径都必须经过 \(D\)。按照常见的无向网络标准化方法，\(D\) 的中介中心性为 \(9/15=0.6\)，而 \(C\) 和 \(E\) 均为 \(8/15\approx0.533\)。

这说明 \(C\) 和 \(E\) 虽然拥有更多直接连接，但 \(D\) 更接近整个网络的中心，并承担更强的跨群体桥梁作用。

如果只追求第一轮直接触达，可以优先选择 \(C\) 或 \(E\)；如果关心跨群体传播和桥梁监测，应优先关注 \(D\)。删除 \(D\) 后，网络分裂为 \(ABC\) 和 \(EFG\) 两个互不连通的分量。因此，关键节点也可以相对于保持连通性、阻断传播或提高系统韧性来定义。

</details>
