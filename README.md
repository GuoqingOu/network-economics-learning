\# Network Economics Learning



这是我的网络经济学学习仓库，用于记录课程笔记、论文阅读、代码复现和练习。



\## 学习目标



\- 掌握网络经济学的基本概念

\- 学习常用网络指标及其经济含义

\- 理解社会学习与网络影响

\- 学习内生网络形成

\- 学习网络博弈与竞争

\- 学习多层网络

\- 使用代码实现和可视化网络模型
